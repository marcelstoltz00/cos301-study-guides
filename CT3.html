Question 1)

Examining the trust boundary and data flow between the Dispatch Command Service, Payments Adapter, and the External Vault / SDK, which security tactic and architectural pattern combination is enforced to ensure compliance with privacy regulations (e.g., POPIA)? Write the correct letter in the answer box:


A. Tactic: Isolate volatile code | Pattern: Model-View-Presenter (MVP) with direct database access

B. Tactic: Reduce attack surface via Tokenisation | Pattern: Adapter pattern encapsulating crypto operations outside the internal DB

C. Tactic: Monolith-first deployment | Pattern: Strangler Fig with shared memory tables

D. Tactic: Synchronous RPC calls | Pattern: Enterprise Service Bus (ESB) layer


Answer: B


Question 2)

If the Notification Worker continuously fails while trying to process messages from the Event Bus due to a malformed payload (poison message), which component in the diagram prevents the worker from entering an infinite crash loop and blocking the pipeline? Write the correct letter in the answer box:

A. The API Gateway throttles incoming HTTPS requests

B. The Circuit Breaker on the Primary Database

C. Routing unprocessable messages to a Queue

D. Increasing the TTL on the Redis Read Cache


Answer: C


Question 3)

The engineering team notices that during high-load periods, updates made via the Dispatch Command Service take up to 2 seconds to reflect in the Tracking Query API due to latency on the Event Bus updating Redis. Which trade-off point is being directly demonstrated here, and what is the correct architectural assessment? Write the correct letter in the answer box:

A. Trade-off: Cache Size vs. Cost. Assessment: The team must double the Redis RAM allocation to fix bus latency.

B. Trade-off: Performance Efficiency vs. Data Consistency. Assessment: The system prioritises high write throughput and loose coupling at the cost of eventual consistency on the read path.

C. Trade-off: Code Coverage vs. Testability. Assessment: The team failed to write unit tests for the Redis cache.

D. Trade-off: Modifiability vs. Security. Assessment: Moving the Redis cache outside the Trust Boundary will eliminate latency.


Answer: B
